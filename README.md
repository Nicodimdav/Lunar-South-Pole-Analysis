# Lunar Horizon — South Pole Mission & Ephemeris Evaluator

## Project Summary
Planning lunar south pole missions requires balancing extreme illumination and communication constraints against complex topography, yet existing tools like NASA Quickmap, Moon Trek, and JPL Horizons feature steep learning curves. To bridge this gap, we developed **Lunar Horizon**, an interactive web-based mission planning and ephemeris workspace built for rapid scenario evaluation. 

The application integrates a physics-based lunar ephemeris and libration engine with 360° topographic horizon occlusion, computing real-time Sun and Earth azimuths, power generation potentials, and Direct-to-Earth (DTE) RF communication windows across a 30-day lunar synodic cycle. Mission planners and educators can instantly compare candidate landing sites—such as Shackleton Rim, Malapert Massif, and Mons Mouton—or simulate launch schedule slips to evaluate trade-offs in power and link availability. 

By translating complex celestial mechanics into clear, interactive visualizations, Lunar Horizon empowers teams to coordinate science and engineering constraints efficiently.
